# KGM BANK

App de banco virtual simples, feito em um único arquivo HTML.

- Saldo e adicionar dinheiro
- Pix simulado (chave, valor, confirmação e comprovante)
- Cartão virtual com débito e bloqueio
- Login com e-mail e senha (simulado, salvo no navegador)
- App instalável (PWA): adicione à tela inicial pelo navegador
- Extrato de movimentações

**É uma simulação.** Nenhum dinheiro real é movimentado. Os dados ficam salvos só no navegador (localStorage).

## Como usar

Abra o `index.html` no navegador ou publique com o GitHub Pages
(Settings > Pages > Deploy from a branch > main > / (root)).
